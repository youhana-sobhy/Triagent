# Certificate expiring

Use this runbook for TLS/SSL certificate alerts. A certificate that expires in more than 7 days is info; in 7 days or fewer it is a warning; an expired certificate is critical, because browsers show security errors and API clients refuse to connect. Check the real expiry date with `openssl s_client -connect <host>:443 -servername <host> | openssl x509 -noout -enddate`. If the certificate is managed by certbot or ACME, run `certbot renew` and look at why automatic renewal failed (DNS, port 80 blocked, rate limit). If it comes from a commercial certificate authority, request a new certificate from the security team. After renewing, install the new certificate on every server and load balancer that serves the domain, reload the web server (`nginx -s reload`), and confirm the new expiry date with the same openssl command.
